# Utility Types

Utility Types — глобально доступные типы для распространённых преобразований. Их не нужно импортировать: определения поставляются вместе с TypeScript. Выберите утилиту — каждая открывается как отдельная страница с объяснением и примерами.

Перечень и поведение сверены с <a className="official-reference" href="https://www.typescriptlang.org/docs/handbook/utility-types.html">официальным справочником TypeScript</a>.

## Важное ограничение

Utility Types существуют только во время проверки типов. Они не фильтруют поля объекта и не изменяют значения в JavaScript.
