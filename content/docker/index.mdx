# Docker с нуля

Этот раздел рассчитан на человека, который раньше почти не работал с Docker. Главы идут последовательно: сначала мы запустим готовый контейнер, затем соберём собственное Node.js-приложение и только после этого перейдём к Docker Compose, PostgreSQL и production-настройкам.

## Главная идея

Представьте обычный рецепт:

- `Dockerfile` — рецепт приготовления приложения;
- image — готовый неизменяемый набор по этому рецепту;
- container — запущенный экземпляр image;
- registry — хранилище готовых images;
- volume — отдельное место для данных, которые нельзя терять вместе с container.

```text
исходный код + Dockerfile
          ↓ docker build
        image
          ↓ docker run
       container
```

В первых главах достаточно понимать эту цепочку. Networks, Compose, secrets и multi-stage builds появятся позже, когда станет понятно, какую проблему решает каждый инструмент.

## Как работать с примерами

Не копируйте сразу весь итоговый Compose-файл. Выполняйте главы по порядку и после каждой команды проверяйте результат. Если команда непонятна, остановитесь на её разборе: в следующих главах предполагается понимание предыдущего шага.

Материалы сверены с <a className="official-reference" href="https://docs.docker.com/get-started/">официальным руководством Docker</a>. В книге используется современная команда `docker compose`, а не старая отдельная программа `docker-compose`.
