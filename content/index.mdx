# TypeScript: ручная книга

Практический справочник по встроенным **Utility Types** TypeScript. Здесь собраны все утилиты из актуального официального Handbook: короткое объяснение, синтаксис и несколько самостоятельных примеров для каждой.

## Как читать книгу

Выберите группу в меню слева. Оглавление текущей главы находится справа на широком экране и в меню на мобильном. Нажатие на заголовок плавно перемещает страницу к нужному разделу.

Каждый пример можно скопировать кнопкой в правом верхнем углу блока и проверить в локальном TypeScript-проекте или официальном Playground.

## Карта материалов

| Группа | Что внутри |
| --- | --- |
| Объектные преобразования | `Partial`, `Required`, `Readonly`, `Record`, `Pick`, `Omit` |
| Объединения | `Exclude`, `Extract`, `NonNullable` |
| Функции | `Parameters`, `ReturnType` |
| Конструкторы | `ConstructorParameters`, `InstanceType` |
| Контекст `this` | `ThisParameterType`, `OmitThisParameter`, `ThisType` |
| Строки | `Uppercase`, `Lowercase`, `Capitalize`, `Uncapitalize` |
| Асинхронность и вывод | `Awaited`, `NoInfer` |

## Принципы примеров

- Все фрагменты рассчитаны на строгий режим TypeScript.
- Строка `// @ts-expect-error` отмечает намеренную ошибку компиляции.
- Утилиты преобразуют типы и не изменяют значения во время выполнения.

Начните с [обзора Utility Types](/utility-types/).
