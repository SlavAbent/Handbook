# Карманная книга разработчика

Практический справочник, который не привязан к одной технологии. Сейчас в книге собраны встроенные хуки **React 19.3**, хуки **React DOM** и **Utility Types** TypeScript.

## Как читать книгу

Выберите группу в меню слева. Оглавление текущей главы находится справа на широком экране и в меню на мобильном. Нажатие на заголовок плавно перемещает страницу к нужному разделу.

Каждый пример можно скопировать кнопкой в правом верхнем углу блока и проверить в локальном TypeScript-проекте или официальном Playground.

## Карта материалов

| Технология | Что внутри |
| --- | --- |
| React | Все встроенные хуки, разделённые по назначению |
| React DOM | Хуки для браузерного DOM и форм |
| TypeScript | Встроенные Utility Types |

## Принципы примеров

- Все фрагменты рассчитаны на TypeScript и TSX в строгом режиме.
- Строка `// @ts-expect-error` отмечает намеренную ошибку компиляции.
- Утилиты преобразуют типы и не изменяют значения во время выполнения.

Начните с [обзора React](/react/) или перейдите к [Utility Types](/utility-types/).
