# React Hooks

Хуки позволяют компонентам использовать состояние, контекст, ссылки, эффекты и конкурентный рендеринг. Вызывайте хуки только на верхнем уровне компонента или собственного хука; исключение по форме вызова — API `use`, который не входит в этот каталог хуков.
